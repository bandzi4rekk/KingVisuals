KingVisuals - Fabric 1.21.4 (Java 21)

1. Skopiuj do tego folderu 'gradle/' oraz 'gradlew' i 'gradlew.bat' z dowolnego swojego projektu Fabric
   (albo uruchom 'gradle wrapper' jesli masz zainstalowanego Gradle).
2. Zbuduj: ./gradlew build   -> gotowy mod w build/libs/kingvisuals-1.0.0.jar
3. W grze: Right Shift otwiera menu.
